Pradeep Food Delivery Website

This is a fully industry-grade e-commerce food delivery website developed completely independently by me. It took me around 2½ weeks to complete. Around 80% of the code was handwritten by me, and the remaining 20% was done with the help of AI tools like DeepSeek (mostly used for debugging and deployment issues while rendering in Render).

Project URL: https://pradeep-food-delivery.vercel.app

The project includes a complete login system with Google Authentication. If a new user registers, there is also a signup page. Additionally, a "Forgot Password" option is available, which sends a verification email via Gmail for resetting the password.

During signup, users can choose one of three roles: User, Shop Owner, or Delivery Partner. Each role has a different dashboard and permissions:
User: Can browse food items, add them to the cart, and place orders.
Shop Owner: Can add, edit, and remove food items, manage stock, and view orders.
Delivery Partner: Can view assigned deliveries and update delivery status.

The website also includes:
A responsive and user-friendly UI.
Real-time data updates using backend APIs.
Cloud image storage through Cloudinary.
Secure JWT-based authentication system.
Email notifications for order and password updates.
Fully deployed backend (Render) and frontend (Vercel).

This project was developed using:
Frontend: React.js, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB Atlas
Authentication: Google OAuth and JWT
Deployment: Render (backend), Vercel (frontend)

Overall, this project helped me understand full-stack development, user authentication, cloud integration, and deployment pipelines.
